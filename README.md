# PhysVisual Physics Lab

Build a complete, modern, premium-looking educational physics simulation web application called PhysVisual.

IMPORTANT: Focus on the frontend and user experience.

Design direction:
Create a futuristic scientific laboratory interface with a professional SaaS aesthetic.

Visual style:

Dark navy background.

Deep blue and purple gradients.

Cyan accent colors.

Glassmorphism used subtly.

Smooth transitions and micro-interactions.

Beautiful typography.

Responsive design.

Requirements:

Use React, TypeScript, Tailwind CSS.

Use reusable components.

Use Lucide icons.

Make all navigation functional.

Add responsive layouts.

Use realistic sample data.

Do not create empty buttons.

Do not make the website look like a generic AI-generated template.

The result should look like a real commercial educational technology startup.

Make the interface visually impressive but keep it practical and easy to navigate.
